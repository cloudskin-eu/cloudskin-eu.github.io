CloudSkin represents a leap forward in cognitive cloud-edge continuum platforms. By integrating AI-driven adaptability with secure execution environments, we aim to solve the complexity of heterogeneous resource management.

CloudSkin Project Overview

Missions

Smart Management

Develop an AI-based “Learning Plane” to automatically orchestrate cloud and edge resources. Decisions will continuously adapt to the environment, including on low-power edge devices.

Virtual Execution

Create a universal execution abstraction (“Cloud-edge cells”) based on WebAssembly. It will enable efficient execution and migration of applications across the continuum, integrated with Kubernetes.

Infrastructure Support

Build a flexible infrastructure supporting short-lived tasks and intense data bursts. Providing near bare-metal performance using RDMA networking and near-storage computing (GPUs, FPGAs).
